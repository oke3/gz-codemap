# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.2.3] — 2026-08-24

### Changed

- Removed promotional footer comments from all generated files; generated output now carries only the `Generated by @oke3/opencode-codemap` version line.
- Relicensed under MIT (c) oke3; removed organization branding from README, templates, and package metadata.

## [0.2.2] — 2026-08

### Fixed

- Pluralization, stale version strings, dead code, race conditions, and test tautology.

## [0.2.1] — 2026-08

### Added

- Version-check guard in the publish step (CI skips publish when the registry already has the version).

## [0.2.0] — 2026-08

### Added

- Multi-tool generation (OpenCode + Cursor + others) from a single scan.
- `update` mode — re-scans and only overwrites files that changed, preserving manual edits.
- `--dry-run`, `--force`, `--quiet` global flags; `scan`/`generate` subcommands with `.scan.json` intermediate format.
- Framework detection expanded (React, Astro, API, and more) with matching agent personas and commands wired from `package.json` scripts.

## [0.1.x] — 2026-07

### Added

- Initial public release: scan any codebase → generate `AGENTS.md`, `opencode.json`, agent personas, and convenience commands.
